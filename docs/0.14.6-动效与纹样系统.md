# 0.14.6 动效系统与纹样系统

这一版把 QML 前端的动效从"各处随手写的 NumberAnimation"收成一套统一规范，并新增了一整套
可复用的纹样绘制系统（六个子系统 + 四个组合模板）。业务逻辑与交互没有改动。

配套阅读：`docs/纹样设计规范.md`（六子系统的完整口径、四种组合模板、动态规则、验收清单）。

## 一、动效系统

### 1. 统一的令牌与缓动（`app_qml/qml/theme.js`）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `DUR_PRESS` / `DUR_HOVER` / `DUR` | 120 / 180 / 240 ms | 按压、悬停、常规状态切换 |
| `DUR_ENTER` / `STAGGER` / `LIFT` | 420 ms / 48 ms / 16 px | 入场时长、逐项错峰、入场位移 |
| `SKEW` | -0.20 | 斜切（擦除带、导航标记的平行四边形） |
| `DUR_WIPE` / `DUR_SWEEP` / `STAGGER_WIPE` | 320 / 560 / 55 ms | 面板擦除、整窗转场带、面板错峰 |
| `DUR_MOVE` | 340 ms | 导航标记滑动 |

缓动选择口径：位移/擦除用 `OutCubic`~`OutQuint`，转场带用 `OutExpo`，
呼吸类循环用 `InOutSine`，按压回弹用 `OutBack`（幅度受控，不做夸张弹跳）。

### 2. 层与镜头

- **分层视差**：指针位置（`HoverHandler`）驱动三层反向位移 —— 流动背景 ±22/14 px、
  版面 ±6/4 px、边注 ±34 px、定位十字 ∓26/20 px。
- **镜头微动**：切页时 `cameraJolt`（260 ms `OutQuint`）让版面轻抖 12 px，
  `breathe`（13 s 往返 `InOutSine`）让版面有 0.6% 的呼吸缩放。
- **常驻动效**：`scanlines`（两条极淡横带 11 s / 7.3 s 循环下落）、`dust`（26 粒微尘）、
  `FlowField`（点阵 / 流线 / 扫光 / 闪烁）、主视觉自转刻度环（96 s）与雷达扫线（24 s）、
  面板头部的数据点（`Plate.packet`）。
- **转场三阶段**：① 面板擦除（`Sweep` 斜切遮罩，逐面板错峰 55 ms）；② 整窗转场带
  （`pageSweep`，`OutExpo` 560 ms）；③ 仪式性纹样层（模板 D 玫瑰窗，`transitionMotif`
  0→1 340 ms `OutCubic`、1→0 520 ms `InOutSine`）。
- **动效档位** `motionTier`（2 完整 / 1 标准 / 0 最低）：最低档只保留必要状态切换，
  常驻动效与转场纹样全部停掉。

### 3. 实测数据（`--perf <秒>`，1440x900 窗口、会话页、常驻动效全开）

| 指标 | 全程（含启动） | 稳态（跳过前 40 帧） |
| --- | --- | --- |
| 采样帧数 | 808 | 768 |
| 平均帧时间 | 14.86 ms（67.3 fps） | 13.45 ms（74.4 fps） |
| p50 | 13.33 ms | 13.32 ms |
| p95 | 28.42 ms | 25.56 ms |
| 最大帧时间 | 500.19 ms（启动期首帧） | 46.77 ms |

进程工作集峰值 **219.6 MiB**（PowerShell 轮询 `WorkingSet64`）。

第一版（修完黄绿线/转场黑块、纹样尚未接入时）同一口径是 `434 帧 / avg 23.06 ms / p95 45.64 ms / 43.4 fps`；
引入纹样图版后不但没有变慢，反而更快 —— 因为纹样图版替代了原来三块各自重绘的旧图版（`HeroPlate` /
`ConstellationPlate` / `RecordPlate`），而它自己只在 12 fps 上推进相位。

纹样图版的单次重绘成本单独量过（临时给 `MO.template()` 加 `Date.now()` 计时）：**avg 3–4 ms、max 6 ms**
（12 fps ⇒ 约 4% CPU），所以常驻画布不是掉帧来源。

复现：`StrongholdLink.exe --windowed --size 1440x900 --page session --perf 12 --log perf.log`
（注意：`--perf` 跑完不会自己退出，日志里出现 `[perf] 稳态 …` 之后手动结束进程即可）。

已知瓶颈：p95 主要来自切页瞬间（转场纹样层 + 擦除 + 面板重绘同帧）与启动期首帧。转场纹样层已加
`active: root.awake && root.transitionMotif > 0.001` 门，平时不重绘；若要进一步压 p95，
下一步是把切页时三页的 Canvas 重绘改成按需（只重绘进入/离开的那一页）。

## 二、纹样系统

### 1. 文件

| 文件 | 作用 |
| --- | --- |
| `app_qml/qml/plate/motifs.js` | 纹样绘制库（`.pragma library`）：六子系统 + 四模板 + 屏幕补偿 |
| `app_qml/qml/Components/MotifPlate.qml` | 纹样图版组件（Canvas 包装，12 fps 相位推进、`revealT` 分层显现） |
| `app_qml/qml/plate/sketch.js` | 底层手绘几何库（纹样库复用它的取点与抖动） |
| `docs/纹样设计规范.md` | 六子系统口径、组合模板、动态规则、验收清单 |
| `test/motifs.test.cjs` | 契约测试（色序、编码、出口、qrc 登记、文档在位） |

### 2. 六个子系统
1. **飞鸟与羽毛**：形态系列 A 展翼 / B 滑翔 / C 上升 / D 侧向 / E 转向 / F 远景 / G 独立羽片，
   由 `POSES` 比例表统一（翼展:体长 ≈ 2.8:1、初级飞羽 3–4 根、尾羽 0.12–0.18 翼展）；
   `flock()` 支持 `arc / line / radial / converge` 四种有意图路径，按 `depth` 决定姿态、
   缩放与透明度，鸟与鸟之间强制留间距。
3. **光环与圣徽**：`halo()` 八类（单环 / 多层同心 / 局部中断 / 带刻度 / 带径向标记 /
   与多边形结合 / 放射光环 / 异常断裂）+ `haloCore()`。
4. **羽翼与放射**：`wing()`（镜像、羽片由短到长、片间留空隙）、`wingArc()`、`radialFeathers()`。
   `wing()` 在 0.14.6 里重写过一次：翼臂不再是水平直线，而是 `arm(u) = cx + dir*span*u,
   cy - span*(0.16*sin(u*π*0.9) + 0.05*u²)` 的真曲率弧；羽片分两级 —— 覆羽（沿 u∈[0.06,0.52]，
   长度 0.10→0.22 span、近竖直）与初级飞羽（沿 u∈[0.38,1.0]，长度 0.30→0.62 span、后掠 0→0.62 rad）。
   旧版"水平臂 + 等长垂直羽片"看起来像一排草而不是翅膀（模板 B 的拱肩双翼最明显）。
5. **圣堂拱与玫瑰窗**：`arch()`（真尖拱：起拱线上两段圆弧交于顶点，`rings` 控制嵌套）、
   `roseWindow()`（`stage` 1 轮 / 2 花瓣 / 3 窗格，支持分层显现）、`columns()`。
6. **神圣几何与技术坐标**：`axisNet()`、`angleScale()`（真实角度数字）、`goldenSpiral()`、
   `polygonNest()`、`zones()`（真实分区编号）、`hairAxis()`、`dashArc()`、`medallion()`。
7. **铭文与印记**：`circularText()`、`seal()`、`serifRule()`、`staffNotation()`、`label()`。

参考图语汇（"看着舒适"那一版）：`backdrop()` 雾底 + 光池、`softMass()` 大块柔光体、
`softGlow()` 主体柔光、`lightShafts()` 竖向柔光带。

### 3. 四种组合模板

| 模板 | 组合 | 用在 |
| --- | --- | --- |
| A | 鸟群 + 圣徽 + 留白 | 会话页主视觉（`MotifPlate { template: "A" }`） |
| B | 羽翼 + 圣堂拱框 | 好友页方版心 |
| C | 鸟群 + 坐标轴 + 几何轨迹 | 设置页方版心 |
| D | 玫瑰窗 + 放射几何 + 少量铭文 | 切页转场（只在 0.9 s 内出现） |

### 4. 屏幕补偿

`motifs.js` 的 `PX = 1/窗口缩放比`（夹在 1–2.4）：线宽 `lw()` 乘 `PX`、透明度随 `PX` 微调，
`PX > 1.45` 时关掉最细一层装饰（颗粒、飘带、小字标注）。`MotifPlate` 用
`mapToItem(null, …)` 量出真实缩放写进 `uiScale`，窗口缩放时自动重绘。

## 三、小分辨率下的版面缩放

- `Main.qml` 的 `fitScale` 有下限 `minScale = 0.60`，窗口更小时不再继续缩小，
  由外层 `Flickable` 视口滚动查看。
- 1440x900 的原始适配是 0.671（一屏看全，未受影响）；1024x720 由 0.463 抬到 0.600。
- 已知副作用：进入可滚动模式后底部导航条会落到折叠线以下，需要滚动才能点到。

## 四、已知问题与未完成

1. 转场模板 D 只在切页瞬间出现约 0.9 s，尚无用例单独验收它（`--sheet` 样张模式可看四模板）。
2. 远景鸟（形态 F）在 0.6 倍以下缩放时偏"草"，需要继续打磨轮廓。
3. p95 帧时间 25–28 ms 仍高于 p50（见上文瓶颈）。
4. `Components/Plate.qml` 等文件里仍有历史遗留的顶格缩进，未统一格式。
5. 小窗口（可滚动模式）下底部导航条落到折叠线以下，方案待定：把底栏挪到窗口层（1:1 常显）或
   抬高 `minScale` 换更大的字。

## 五、两个已经踩过、值得记下来的坑

1. **8 位十六进制色是 `#AARRGGBB`，不是 CSS 的 `#RRGGBBAA`。** 写反了不报错，只是颜色整个变样：
   `#ffffff8c` 会被当成"不透明的淡黄"（黄绿色线条的来源），`#22282b00` 会被当成"近黑的半透明"
   （切页遮罩大块纯黑的来源）。回归护栏：`test/motifs.test.cjs` 第一条会用调色板前缀比对把所有
   8 位色扫一遍。
2. **标题栏 `chrome` 是 `z: 1200` 且有一层不透光纸底，任何要显示在它上面的东西 z 必须更大。**
   题词那一行曾经用 `z: 400`，于是文字一个像素都画不出来（几何、透明度、日志全部正常），
   表现为"功能通了但屏幕上看不见"。回归护栏：`test/motifs.test.cjs` 里那条 z 序断言。
   另外 `app_qml/qml.qrc` 新增文件后必须重跑 `qmake` 再 `make`，否则 rcc 不会把新文件编进去
   （`make` 还会报 `Nothing to be done`）。
