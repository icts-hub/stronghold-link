# 中继服务端部署

服务端已实现并在本机端到端验证过（见 `test/relay-server.test.cjs`、`test/relay-client.test.cjs`）。
**目前尚未部署公网实例**；界面里 `Stronghold Relay — NOT DEPLOYED` 的标注在真正部署并实测前不会改。

## 1. 启动

```powershell
# 最小启动：监听 40000，口令从环境变量取（不要写进命令行历史）
$env:SHL_RELAY_TOKEN = "<自己生成的强口令>"
node -e "const {createRelayServer}=require('./network/relay/server.cjs');(async()=>{const s=createRelayServer({sessionToken:process.env.SHL_RELAY_TOKEN,host:'0.0.0.0',port:40000});const i=await s.start();console.log('listening',i.port);setInterval(()=>{const t=s.getStats();console.log(JSON.stringify({peers:t.peersActive,fwd:t.packetsForwarded,bytes:t.bytesForwarded,dropped:t.dropped}))},30000)})()"
```

放行 UDP 端口（示例：Windows 防火墙）：

```powershell
New-NetFirewallRule -DisplayName "Stronghold Relay 40000" -Direction Inbound -Protocol UDP -LocalPort 40000 -Action Allow
```

## 2. 可直接调的上限参数

`createRelayServer({ ... })` 支持：`maxSessions`（默认 32）、`maxPeersPerSession`（默认 8）、
`idleTimeoutMs`（默认 60 秒）、`maxPacketBytes`（默认 1200）、`ratePerSec`（默认不限速，公网建议 200–500）。

公网部署建议：`ratePerSec: 300`、`maxPeersPerSession: 2`、`idleTimeoutMs: 30000`。

## 3. 常驻运行

Linux（systemd）：

```ini
[Unit]
Description=Stronghold Relay
After=network.target

[Service]
Environment=SHL_RELAY_TOKEN=<口令>
WorkingDirectory=/opt/stronghold-link
ExecStart=/usr/bin/node tools/relay-daemon.cjs
Restart=always
User=shl

[Install]
WantedBy=multi-user.target
```

Windows：用 `nssm` 或 `pm2` 把 `node tools/relay-daemon.cjs` 注册成服务。

## 4. 健康检查（可用于监控）

```powershell
node tools/relay-health.cjs <主机> <端口> <口令> 5
```

退出码：`0` 正常、`1` 入会失败、`2` 心跳全部超时、`3` 抖动或丢包超阈值。

## 5. 安全边界（部署前必读）

- **必须设置口令**：没有口令时构造函数直接拒绝启动，避免成为开放 UDP 代理
- **只在本会话内两两转发**：不回给发送方、不跨会话、不转发给未入会地址
- **不加密载荷**：中继只转发字节；加密由上层安全通道（会话口令）负责，部署方看不到明文也**不做任何审计留存**
- 包大小上限默认 1200 字节；超限丢弃并计数
- 令牌桶限速超限即丢，不排队（防止被当成放大器）
