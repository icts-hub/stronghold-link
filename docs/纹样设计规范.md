# 纹样设计规范

## 1 文档目的与适用范围

本规范是《专项设计任务：建立具有神圣象征、飞鸟纹样与精密几何语言的完整视觉设计系统》的施工依据。此后所有页面、图版与动画一律按本规范调用纹样，不再逐页自创装饰。

- 唯一入口：`source/app_qml/qml/plate/motifs.js`（`.pragma library`，约 1600 行，仍在迭代）与 `source/app_qml/qml/Components/MotifPlate.qml`（95 行）。页面只能通过 MotifPlate 调用 `MO.template()`，不得在页面里手写圆弧、刻度或鸟形。
- 与 `theme.js` 的分工：`theme.js` 管底色、文字色、时长与动效档位（`DUR_ENTER = 420`、`STAGGER = 48`、`DUR_WIPE = 320`）；纹样自己的颜色写在 motifs.js 的 `var C` 里。两套令牌只共享字面值（`cobalt = #3a5bc2`、`ink = #22282b`、`paper = #eff1ef` 同值），不共享代码，改色时两处都要看。
- 与 `sketch.js` 的关系：`source/app_qml/qml/plate/sketch.js` 是旧的"手绘线条"语言（`birdPath`、`dove`、`flower`、`ringPts` 等），**冻结**：不再新增调用、不再扩展。它今天的正当用户只有旧组件——`Components/WingMark.qml`、`HeroPlate.qml`、`ConstellationPlate.qml`、`RecordPlate.qml`、`FlowField.qml`。新纹样一律进 motifs.js。
- 与旧图版的关系：`plate/hero.js`（HeroPlate）、`plate/people.js`（ConstellationPlate / PersonPlate）、`plate/record.js`（RecordPlate）是与旧 sketch 语言同代的构图，正被模板 A/B/C 逐页取代，不得作为新页面的参考。
- 能力边界：本规范只管"纹样层"（几何、比例、描边、透明度、动效）。刊头文字、按钮、列表、状态读数属于 `theme.js` 与各页 UI 规范，纹样层不得侵入。
- 术语统一：圣徽（同心圣环）、玫瑰窗、羽片、羽翼、分区标签、游标轴、铭文、图版、组合模板。全项目只用这套中文术语。

## 2 设计前提

### 2.1 视觉概念的四个来源

| 概念 | 承担元素 | 实现位置 |
| --- | --- | --- |
| 神圣象征 | 圣徽、玫瑰窗、圣堂拱、铭文 | `halo` / `haloCore` / `roseWindow` / `arch` / `circularText` / `seal` |
| 有机形态 | 飞鸟、羽片、羽翼 | `bird` / `flock` / `feather` / `featherFan` / `wing` / `wingBand` |
| 建筑秩序 | 尖拱、柱列、层台、龛位 | `arch` / `columns` / 模板 B 的层台与龛位 |
| 技术几何 | 坐标网、角度刻度、分区标签、轨迹、游标轴、虚线弧 | `axisNet` / `angleScale` / `zones` / `goldenSpiral` / `hairAxis` / `dashArc` |

四者不是并列装饰，而是"有机主体（鸟）＋结构与秩序（拱、几何）＋象征（圣徽、铭文）"的层级关系：几何是引导线，圣徽是中心，鸟是唯一的主体。

### 2.2 参考图分析结论（实测，不得改动）

对《明日方舟》六周年与「众生行记」界面截图的实测结论，作为本规范的基准色调与构图依据：

- 基调：极浅、通透、雾感冷色（冰蓝、珍珠白、淡青灰），几乎不用黑色重线；最深的颜色只出现在少量 UI 底色与小组件上，另有极少量暖橙红作点缀。
- 主体纹样：巨大的半透明白色飞鸟／羽翼剪影压在画面左上与右下角，被画面边缘裁切，柔和、明亮、不描重边。
- 几何：人物背后有大面积极淡的同心圆弧与放射扇线；圆形刻度环（十字线 + 刻度）作为准星式标记；`A1/A2/A3` 分区小标签、`X/Y` 轴与细测量线；细虚线弧（绳／链状）斜穿画面一角。
- 铭文：中文衬线大标题字距很开，配极小号英文衬线副题与等宽小字数字。
- 构图：不对称、分层；主体偏右，标题在左、小圆徽与说明在下方；上方留大片空白；所有元素低对比、互相"透"。
- 舒适感来源：没有纯黑重线；亮线多于暗线；细节靠小尺寸高精度元素（细刻度、小标签）而非粗线；大量留白与柔和光晕；元素成小簇分布而不是铺满。
- 结论：实现要往"轻、亮、透、疏"走——线用冰蓝／珍珠白，少量海军蓝做重音；鸟做成大面积半透明亮剪影并可被画面边缘裁切；刻度环、小徽章、分区标签走"小而精"；禁止用大面积深色填充压住纸面。

### 2.3 总体气质与"看着舒适"的可执行判据

四条判据都可以在代码里核对，也可以在截图上量：

1. **亮度分布**：图版必须叠在纸面上——底色取 `theme.js` 的 `PANEL_TOP = #f4f6f4`、`PANEL_BOTTOM = #e7eae9`、`PAPER = #e9ecec`、`PAPER_LOCAL = #eff1ef`。禁止纯黑（`#000`）与任何大面积深色填充；最深的两个色 `navy = #1e2c4b`、`ink = #22282b` 只能出现在细线、小圆徽、小标签上，单块图版里深色像素面积目测不超过 2%。
2. **对比分层**：透明度分三层，数值指写进 `alpha()` 的数字（渲染时会统一乘 `VIS = 1.55`，所以写 0.42 实际画到 0.65）——主体 0.55–0.72、辅助 0.28–0.42、刻度与注记 0.14–0.26；相邻两层之差不少于 0.15，否则层级读不出来。
3. **留白**：主纹样的圆心必须避开文字区。模板 A 默认圆心在 `w * 0.62`、`h * 0.44`，左侧 0–0.40w 是文字负空间；标题栏一行文字不得压进主纹样直径范围内。
4. **密度**：元素成簇分布。鸟与鸟之间由 `flock` 强制间距否决——新鸟与前鸟的距离小于 `(前鸟翼展 + 新鸟翼展) * 0.38` 时重掷，最多 6 次，仍不合格就放弃这只鸟；因此鸟群天然有疏有密，不会均匀铺满。

### 2.4 总体禁止事项

- 禁止发光（`shadowBlur`）、渐变阴影、厚描边、金属质感、位图贴图。柔光一律用"宽而淡的同色描边 + 径向渐变色块"叠出来。
- 禁止给纹样加不透明填充形成色块（例外只有鸟的柔光体与羽片的极薄填充，见 3.1、3.3）。
- 禁止在页面里另起一套几何：所有线条的线宽必须经过 `lw()`，所有透明度必须经过 `alpha()`。
- 禁止一个画面出现两个主纹样、两个中心、两种环形铭文。

## 3 六子系统规范

### 3.0 公共基础件与令牌

所有子系统都由同一组基础件搭出来，改任何子系统前先认这组数：

| 名称 | 签名 / 取值 | 口径 |
| --- | --- | --- |
| 调色板 | `var C` | ivory `#f5f2ea`、pearl `#eef2f4`、ice `#c3d9e8`、iceDeep `#8db4d4`、cyan `#a9ccd5`、silver `#98a2a6`、silverSoft `#bcc4c7`、gold `#c1a05e`、goldSoft `#d9c391`、navy `#1e2c4b`、ink `#22282b`、cobalt `#3a5bc2`、azure `#4c92d4`、paper `#eff1ef` |
| 常量 | `TAU = Math.PI * 2`、`PHI = (Math.sqrt(5) - 1) / 2`（0.618） | 一切角度与增长只用这两个数推导 |
| 随机 | `rng(seed)` | 确定性线性同余（`s = (s * 16807) % 2147483647`），同种子必出同图 |
| 数值 | `clamp(v, a, b)`、`lerp(a, b, t)` | 插值只用这两个 |
| 线宽 | `lw(base)` → `clamp(base, 0.70, 1.9)` | 所有线的唯一入口；刻度线一律 ≤ 0.9 |
| 抖动 | `wob(r, amp)` → `(r() - 0.5) * 2 * amp`（缺省 0.6） | 允许"手绘抖动"，不允许随机摆放 |
| 透明度 | `alpha(ctx, a)` → `globalAlpha = clamp(a * 1.55, 0, 1)`，`var VIS = 1.55` | 所有 alpha 的唯一入口 |
| 极坐标 | `pol(cx, cy, rad, ang)` | 圆弧上的点一律由它算，不手写正余弦 |
| 弧线 | `strokeArc(ctx, cx, cy, rad, a0, a1, r, amp)`（amp 缺省 0.7）、`strokeCircle(ctx, cx, cy, rad, r, amp)` | 弧按约 0.12 rad 一段离散采样，段数 ≥ 6，抖动沿半径方向 |
| 点与刻度 | `dot(ctx, x, y, rad, color, a)`、`tickRing(ctx, cx, cy, rad, count, len, r, color, a, phase)` | 刻度环 `lw(0.8)`，每 3 根一根长刻度，其余 ×0.55 |
| 曲线 | `qp(p0, c, p1, t)`、`cp(p0, c1, c2, p1, t)`、`trace(ctx, pts, sub)` | 采样点接路径；`sub = false` 起笔、`true` 续画 |
| 背景层 | `lightShafts(ctx, w, h, r, opt)`、`softGlow(ctx, cx, cy, rad, color, a)`、`softMass(ctx, cx, cy, rx, ry, r, opt)` | 竖向柔光带（缺省 7 条、带宽 `w * 0.018–0.075`、`alpha 0.30`、另补 3 根象牙白高光线 `lw(0.7)` ／ α0.42）、主体背后柔光（缺省 `a = 0.34`）、大块柔光体（`core` 0.18、可选 `grain` 等值线与 `wisps` 飘带） |
| 小而精 | `hairAxis(ctx, x0, y0, x1, y1, r, opt)`、`dashArc(ctx, cx, cy, rad, a0, a1, r, opt)`、`medallion(ctx, cx, cy, rad, r, opt)` | 细测量轴 `lw(0.7)` α0.52（端刻度 ±4、中刻度 ±3、次刻度 ±2，标注 α0.66）；虚线弧 `lw(0.8)`、`dash 7 / gap 5`、α0.46、头部一枚 9px 方向小三角；小圆徽方框边长 `rad * 2.5`、`lw(0.75)` α0.46 |

绘制顺序固定：背景层（光带、柔光）→ 辅助几何 → 圣徽／玫瑰窗／拱 → 鸟与羽翼 → 铭文与小徽章。引导线永远画在鸟下面，且比鸟淡。

### 3.1 子系统一：飞鸟与羽毛

**基本几何结构**：鸟在内部坐标里以半展长为 1 作图——头在 +x、尾在 -x、双翼沿 ±y 展开；七种姿态（`POSES`）共用同一套脊线、双翼、尾扇与羽片缺口生成逻辑，只有姿态参数不同：

| 形态 | span 展翼 | dihedral 二面角 | sweep 后掠 | primaries 初级飞羽 | tail 尾羽 | pitch 俯仰 |
| --- | --- | --- | --- | --- | --- | --- |
| A 展翼 | 1.00 | 0.10 | 0.10 | 4 | 0.16 | 0.00 |
| B 滑翔 | 0.94 | 0.24 | 0.20 | 4 | 0.15 | 0.03 |
| C 上升 | 0.86 | 0.42 | 0.14 | 3 | 0.18 | -0.12 |
| D 侧向 | 0.90 | 0.16 | 0.30 | 4 | 0.15 | 0.00 |
| E 转向 | 0.82 | 0.30 | 0.38 | 3 | 0.14 | 0.06（`asym = 0.26`） |
| F 远景 | 0.64 | 0.20 | 0.18 | 0（只留轮廓） | 0.12 | — （`far: true`） |
| G 独立羽片 | 0.46 | 0.06 | 0.00 | 5 | 0.00 | — （`single: true`） |

**轮廓与比例（硬口径）**：

- 翼展 : 体长 ≈ **2.8 : 1**——`bird(ctx, cx, cy, s, poseKey, ang, r, opt)` 里 `s` 是整只鸟的翼展像素，体长 `bl = s * 0.36`。
- 体半宽 `bw = s * 0.052`；头在 `bl * 0.60` 处、头半径 `hr = bw * 0.78`；喙为三点折线，长 `hr * 2.30`。
- **翼根弦 = 0.26 倍翼展**：在 `wing()` / `featherFan()` 里对应 `len0`（翼根初级飞羽长度系数），模板 B 取 `len0: 0.26`，函数缺省 0.24。
- **初级飞羽 3–4 根**（A/B/D 4 根、C/E 3 根、F 0 根、G 5 根），在后缘上按 `round(18 * (0.16 + 0.60 * k / (n - 1)))` 的位置切出缺口，每根再向外抬 `0.10 + 0.05k` 倍半展。
- **尾羽 0.12–0.18 倍翼展**，三根，展开 ±15°（`π ± 0.26` rad）。
- 举翅即投影变短：`lift = clamp(dihedral + flap * 0.16, 0, 0.62)`，半展长 `half = s * 0.5 * spanScale * (1 - lift * 0.34)`。
- 转向（E）靠 `asym` 让两侧翼展不等，并在 `flock` 里给航向加 `0.18π` 偏角。

**材质（四步，缺一不可）**：

1. 挖空——`destination-out`、`globalAlpha 0.94`（`opt.cut` 缺省 true），鸟因此是版面上的"留白"，不是压在网格上的墨块；
2. 柔光体——象牙白 `C.ivory` 填充，近景 `massAlpha 0.30`、远景 0.16；
3. bloom——珍珠白 `C.pearl`、线宽 `w * 5.5` 的宽边，近景 α0.15、远景 0.07（用两道粗细不同的线叠出柔光，不用 shadowBlur）；
4. 轮廓——近景 `C.navy`、远景 `C.iceDeep`，`lw(0.9)` / `lw(0.6)`，α0.46 / 0.28；翼内分隔线 3–4 道、α 为轮廓的 0.62。

**羽片**：`feather(ctx, x, y, len, wid, ang, r, opt)`——根部窄、`0.42 * len` 处最宽、尖端收成一点；描边缺省 `C.silver`、`lw(0.7)`、α0.5；填充缺省 `C.pearl`，`fillAlpha` 0.42 再乘 α 与 1.8、上限 0.85；羽轴 `lw(w * 0.8)`、α 为 0.72；3 道羽枝 `lw(w * 0.62)`、α0.42、越靠尖越短。`featherFan(ctx, cx, cy, rad, a0, a1, count, r, opt)` 排扇：靠内短（`len0` 0.44）、靠外长（1.0）、宽 `len * 0.082`、相邻留空隙，`t` 控制逐根显现（`shown = round(count * t)`）。

**主／辅**：鸟是唯一有机主体，属于主体层（模板里 `alpha` 0.70–0.82）；羽片、羽翼属于辅助层。

**适用位置与场景**：主视觉的英雄区、标题页、转场；大剪影专用于画面角部并被边缘裁切；远景小队只用于填充上部空白。

**组合方式**：`flock(ctx, spec)` 是唯一成群入口，`spec` 支持 `path`（`"line"` / `"arc"` / `"radial"` / `"converge"`，另有 `"scatter"` 与 `"arc"` 走同一分支，不是独立算法）、`count`、`size`、`sizeMin`（缺省 0.62）、`alpha`（0.56）、`phase`、`seed`（7）、`poses`、`poseShift`、`farPose`、`squash`（0.72）、`flap`、`line`、`lineAlpha`、`fill`、`cut`，线上用 `x0/y0/x1/y1/bow`、环上用 `cx/cy/rad/a0/a1`（缺省 `1.05π → 1.95π`）。远景自动降级：`depth > 0.76` 且 `farPose !== false` 时改用 F 形态；`depth > 0.55` 用 `C.navy`、否则 `C.iceDeep`；`alpha` 按 `lerp(0.36, 1, depth)` 衰减；尺寸按 `size * lerp(sizeMin, 1, 1 - depth) * (1 + wob 0.09)`。

**多股编队（"浩浩荡荡"的口径）**：用户明确要求"鸟多一点，繁杂一点，不要只有一列，要浩浩荡荡的"，所以 `flock` 支持**多股**：

- `streams`（股数，缺省 1）：一条主路径横向错开若干股，**不是一条线上排一列**。内部由 `flockBand` 逐股编排，股与股共享同一张"已放置"表，所以多股之间也不会叠在一起。
- `lateral`（股间距）：沿线路径按**法向**平移（`line` 分支用 `(-dy, dx)/len` 求法向），`arc` 分支改成半径与起止角同时错开（`radFan` / `aFan`）。
- `depthFall`（缺省 0.42）：外侧的股更小更淡（`depthK = 1 - |off| * depthFall`），于是鸟潮有前后厚度，而不是一层贴纸。
- 每股的条数按 `total * (0.66 + 0.34 * sin(π * (0.30 + 0.70 * f)))` 分配 —— 中间股密、外侧股疏。
- `wander`：股**内部**的上下浮动，让每一股本身也是一条有厚度的带。
- `minGap`（缺省 0.38）：防重叠系数；**远景层给 0.22**，允许小鸟互相叠一点，读起来才是"雾一样的鸟潮"而不是整齐的点阵。

**成本分档（决定了能画多少只）**：`bird()` 里对**远景鸟、翼展 ≤ 30 设计像素的鸟**自动进廉价档 —— 不画柔光体（mass）也不画 bloom 宽描边，贝塞尔采样从 18 段降到 10 段；另外**翼展 < 56 设计像素的鸟一律不画 bloom**（只有近景大鸟吃得到那道"柔光边"）。这三条是把一张版心从 33 只做到 ~80 只还不掉帧的关键：实测 138 只 / 10fps 时稳态帧时间劣化到 avg 37.7ms（26.5fps），加上廉价档与 79 只后回到 avg 16.8ms（59.6fps）。

**当前密度（实测，`tools/bird-count` 口径）**：模板 A **79 只**（原版 33）、模板 C **64 只**（原版 14）、模板 B **22 只**（原版 7）；A 的鸟横向铺开 114%、纵向 146%（超出画布的四角由边缘裁切，符合"大剪影被框裁切"的口径）。回归护栏见 `test/motifs.test.cjs` 的"鸟群要浩浩荡荡"一条：鸟数、铺开比例、以及"三股编队的法向铺开必须明显大于单列"。

**动画**：见第 5 节。鸟本身不读时间，只接受 `flap` 与 `phase`。

**禁止变体**：禁止实心深色鸟（挖空后只能填象牙白／珍珠白）；禁止用 `ink` 勾轮廓；禁止把 F 形态当近景主体；禁止 G 形态进鸟群（它只做独立羽片）；禁止翼展与体长比例偏离 2.8:1；禁止逐帧改变形态参数（只允许 `flap` 影响展翼与俯仰）；禁止给鸟加眼睛、喙内填充、羽毛纹理。

### 3.2 子系统二：圣徽

**基本几何结构**：`halo(ctx, cx, cy, r, kind, rnd, opt)` 是"基数环 + 一层内环"的复合结构。基础线宽 `base = lw(r * 0.0055 + 0.7)`，外环半径 `r`、α0.62，`t` 驱动描圆（弧从 0 长到 `TAU * t`，这是"圣徽逐步描绘"的实现）。内层由 `kind` 选一种：

| kind | 结构 | 数值 |
| --- | --- | --- |
| 1 | 双同心环 | `r * 0.86` α0.34 `lw(0.8)`；`r * 0.72` α0.22 `lw(0.7)` |
| 2 | 六段断弧 | 半径 `r * 0.88`，每段留 0.42 rad 缺口，α0.34 `lw(0.9)` |
| 3 | 细分刻度环 | `tickRing(r * 0.97, 48 格, 长 r * 0.055, α0.22)` + 内环 `r * 0.86` α0.30 |
| 4 | 径向标记环 | 12 根 `r * 0.90 → 1.06` 刻度 `lw(0.75)` α0.26 + `r * 1.14` 处圆点（≥1.1px，α0.3）+ 内环 `r * 0.80` α0.24 |
| 5 | 双多边形 | 六边形（`opt.sides` 可改）`r * 0.66` / `r * 0.52`，第二层旋转 `π / sides`，α0.30 `lw(0.85)` |
| 6 | 放射光 | 32 根射线（`opt.rays`）`r * 1.10 → 1.34`（偶数根长）／`1.22`（奇数根），α0.20 `lw(0.7)` + 内环 `r * 0.84` α0.26 |
| 7 | 异常态 | 偏心 + 断裂弧：`r * 0.94` 弧 α0.40、`r * 1.10` 弧 α0.22，再加一小段 `C.gold` 弧（偏心 `(+0.10r, -0.06r)`，半径 `r * 0.62`，α0.28） |

**中心**：`haloCore(ctx, cx, cy, r, rnd, opt)`——十字轴（横 ±0.30r、纵 ±0.42r，`lw(0.9)` α0.5）+ 小圆 `r * 0.16`（`lw(0.7)` α0.34）。它保证纹样缩到很小仍然认得出中心，任何圣徽都必须带它。

**比例与组合**：同心多层，最大与最小半径之比不小于 2.4（模板 A 用 `rad`、`1.16rad`、`0.98rad`、`0.46rad` 四层 + 核心）；内层永远比外层淡。颜色只在 `cobalt`（主）、`iceDeep`（副）、`ivory`（环内放射光，kind 6 专用）之间选。

**适用位置与场景**：模板 A 的绝对中心、模板 B 的龛位之上、模板 D 的玫瑰窗中心、任何"准星式"标记位置。印章式的小徽章用 `medallion`（`rad` 0.046×min(w,h) 量级），不要缩小的 `halo`。

**禁止变体**：禁止给圣徽加填充或发光；禁止同一画面出现两个不同中心的圣徽；禁止 `kind 7` 用于常规页面（只用于"异常／破坏"语义）；禁止把 `kind 3` 的刻度数改成非整除 360 的值。

### 3.3 子系统三：羽翼与放射纹样

**`wing(ctx, cx, cy, span, dir, rnd, opt)` 单侧羽翼**：一条平滑的"臂"（16 段，抬升 `sin(u * π * 0.62) * span * 0.13`，`wob 0.5`）+ 沿臂外侧 3/4 排开的初级飞羽 + 根部覆羽。羽片取臂上 `round(lerp(2, 16, f))` 的位置，长度 `span * lerp(len0 0.24, 0.66, f) * (1 + wob 0.05)`，宽度为长度的 0.082，角度 `-π/2 + dir * lerp(a0 -0.44, a1 0.42, f)`，越靠外越亮（`0.72 + 0.28f`）；臂线 `lw(0.7)`、α 为 `lineAlpha * 0.8`。缺省 `count` 12（下限 4），`lineAlpha` 0.46，`fillAlpha` 0.30。

**`wingBand(ctx, x, y, w, h, rnd, opt)` 装饰羽片带**：横向排列，缺省 9 根，长度按 `h * (0.55 + 0.45 * sin(kπ))` 形成中间长两端短的包络，宽度为长度的 0.16，全部竖直朝上（`-π/2`），`lw(0.7)`、`lineAlpha` 0.45、`fillAlpha` 0.30。

**`radialFeathers(ctx, cx, cy, r0, r1, count, rnd, opt)` 放射羽线**：等分角（`(i / count) * TAU + 0.008`），内外交替长度 0.82 / 1.0 倍，`lw(0.62)`，α 0.16（每第 3 根 +0.10），按 `(i / count) > t` 截断——这是"放射扇线"唯一的实现，永远细、疏、等分。

**主／辅**：双翼在模板 B 里是主体（与拱并列），其余场合是辅助。放射羽线永远是辅助（α ≤ 0.26）。

**组合方式**：双翼必须关于中轴对称——`dir` 取相反数，`a0` / `a1` 互换（模板 B 左翼 `-0.46 / 0.54`、右翼 `-0.54 / 0.46`），两翼尖不越过画面中线；羽片一律由短到长、彼此留空隙，风格与 `feather` 完全一致（同一个函数）。`wingBand` 用于角部或边缘的装饰带，不与双翼同处一个中心。

**禁止变体**：禁止单侧只用一支翼当对称结构；禁止羽片等长或填实；禁止用放射羽线当主体；禁止 `radialFeathers` 的透明度超过 0.26 或改非等分角。

### 3.4 子系统四：圣堂拱形与玫瑰窗

**`arch(ctx, cx, baseY, w, h, rnd, opt)` 尖拱**：真实结构逻辑——两个圆心落在起拱线两端、半径都是 `ww / 2`，两段弧交于顶点。起拱线 `sp = baseY - hh`，弧角 `0 → -0.32π`（左心）与 `π → 1.32π`（右心），拱脚线两端各外伸 4px。嵌套拱逐层内缩 `inset = min(w, h) * 0.055`；第 0 层 `lw(1.0)` α0.42，内层 `lw(0.72)` α0.24。缺省色 `C.iceDeep`，主拱可用 `C.cobalt`。

**`roseWindow(ctx, cx, cy, r, petals, rnd, opt)` 玫瑰窗**，三层：

1. 轮——外圈 `lw(1.1)` α0.52、内轮 `r * 0.86`、心轮 `r * 0.20`（`lw(0.8)` α0.30），圆全部用 `strokeCircle(..., r * 0.003)` 带轻微抖动；
2. 花瓣——每瓣由两段反向二次曲线构成：瓣尖 `r * 0.84`、瓣心 `r * 0.42`、控制点半径 `pr * 0.62`（`pr = r * 0.66`）、控制角 `±0.62π`，弧收于 `r * 0.30` 处，主弧 `lw(0.85)` α0.38；中脊 `r * 0.20 → 瓣尖`，`lw(0.6)` α0.22；瓣间小尖拱格 `r * 0.86 → 0.98`，用 `opt.aux`（缺省 `iceDeep`）`lw(0.6)` α0.20；
3. 外圈窗格——`tickRing(r * 1.02, petals * 2, 长 r * 0.045, α0.20)`。

`opt.stage`（缺省 3）驱动分层显现：1 只画轮、2 加花瓣、3 加窗格。

**柱列**：`columns(ctx, x0, x1, yTop, yBot, count, rnd, opt)`——首末柱 `lw(0.85)` α0.30、中间柱 `lw(0.6)` α0.18，底端抖动 0.8。

**组合方式**：玫瑰窗嵌在拱头（模板 B：圆心 `baseY - ah * 0.60`、半径 `aw * 0.17`、10 瓣），拱是框、窗是心；独立使用时（模板 D）12 瓣、半径 `min(w, h) * 0.30`。"透光"靠的是背后 `softGlow` 与低透明度，不靠填充。

**禁止变体**：禁止圆拱（弧角必须 0.32π，尖顶是这套语言的识别点）；禁止给拱或玫瑰窗填色；禁止花瓣数非整数或小于 6；禁止同画面叠两层以上玫瑰窗；禁止把玫瑰窗放在非拱顶、非中心的位置。

### 3.5 子系统五：神圣几何与技术坐标

技术标记的原则是"轻、细、疏"：只用真实的等分与角度，绝不放假数据或乱码。

- `axisNet(ctx, x, y, w, h, rnd, opt)`——网格 `lw(0.55)` α0.16（`step` 缺省 40，模板按 `max(26…30, w * 0.034…0.05)` 给）；纵线按 `gx / w ≤ t` 逐条出现，横线按 `w * min(1, t * 1.2)` 延长；主坐标轴从左下角向右、向上，`lw(0.9)` α0.30，端点画 ±4px 定位十字（`lw(0.7)` α0.34）。
- `angleScale(ctx, cx, cy, rad, stepDeg, rnd, opt)`——每 `stepDeg` 一根刻度；90° 整数倍为长刻度（`rad * 0.075`、`lw(0.85)` α0.34），45° 倍数取 `rad * 0.05`，其余 `rad * 0.03`（`lw(0.6)` α0.18）；标注只在长刻度处、`9px Consolas, monospace`、写在 `rad + len + 9` 处、α0.36，内容必须是真实角度（`0°`、`90°`…）。
- `goldenSpiral(ctx, x, y, s, turns, rnd, opt)`——对数螺旋，`rr = s * (PHI + 1) ^ (a / (π / 2)) * 0.06`，步数 `round(120 * turns)`，`lw(0.62)` α0.22，缺省 `goldSoft`。它只是构图辅助线，永远最淡。
- `polygonNest(ctx, cx, cy, rad, sides, layers, rnd, opt)`——多边形嵌套，第 k 层半径 `rad * (1 - k * 0.22)`，每层旋转 `π / sides`，`lw(0.85)` / `lw(0.62)`，α0.30 / 0.18，缺省 `cobalt`。
- `zones(ctx, x, y, w, h, cols, rows, rnd, opt)`——分区：只画内部分格线（`lw(0.55)` α0.16），每格左上角内缩 4px 写 `A1`、`A2`…（`8px Consolas, monospace`，α0.30），编号必须按行列顺序，不重复不跳号。
- 小件：`hairAxis`（游标轴，标注 X / Y / 真实数值）、`dashArc`（斜穿画面的绳链）、`medallion`（小圆徽 + 分区标签 + 十字刻度）。

**主／辅**：全部属于辅助层或刻度注记层；唯一的例外是模板 C 的几何轨迹线（`C.iceDeep`、`lw(0.7)` α0.30），它是主体鸟群的运动依据，但仍比鸟淡。

**禁止变体**：禁止网格线亮于 0.26；禁止编造角度与编号；禁止用实线代替虚线弧；禁止让技术标记成为画面最亮或最深的元素。

### 3.6 子系统六：铭文、刻印与仪式标记

- `circularText(ctx, cx, cy, rad, text, rnd, opt)`——逐字沿圆周排版，字顺时针旋转 `a + π/2`；总弧长 `span = min(TAU * 0.92, 字符数 * gap)`，`gap` 缺省 0.115 rad；字体 `9px Consolas, monospace`（`opt.size` 可调），缺省 α0.42，按 `i / len > t` 逐字显现。文本必须是真实英文大写短语，词间用中点 `·` 分隔，末尾留一个中点表示环形连续。
- `seal(ctx, cx, cy, rad, text, mark, rnd, opt)`——外环 `lw(0.9)` α0.44、内环 `r * 0.84` `lw(0.6)` α0.24、环形铭文在 `r * 0.92` 处 α0.40、中心记号用 `600 <rad * 0.42>px Georgia, serif` α0.5。
- `serifRule(ctx, x, y, w, rnd, opt)`——细分隔线 `lw(0.6)` α0.34，长度随 `t` 生长，两端各一枚菱形节点（±4 × ±3.4，α0.40）。
- `staffNotation(ctx, x, y, w, rnd, opt)`——五线谱符号：五线间距 3.4、`lw(0.5)` α0.20；音符椭圆 2.6 × 1.9 旋转 -0.35、符干 8px、`lw(0.7)` α0.42，位置由一个独立种子决定，不随主种子漂移。
- `label(ctx, x, y, text, rnd, opt)`——小标签，缺省 `10px`、α0.5、左对齐，字间插 `U+2009` 细空格（等宽小字是参考图的排印特征），按 `t` 逐字显示。

**排印层级**（与参考图一致）：中文衬线大标题（字距很开，属 UI 规范）＋极小号英文衬线副题（模板 `caption`：`SANCTUM`、`STEAM LOBBY`、`TRAJECTORY`、`ROSE WINDOW`）＋等宽小字数字与坐标。环形铭文总长不超过 34 个字符；同一画面只允许一处环形铭文。

**禁止变体**：禁止编造文本、乱码或占位符号；禁止给铭文加描边、阴影、发光；禁止用无衬线正文体写环形铭文；禁止在同一画面出现两种环形铭文或两个 `seal`。

## 4 四种组合模板的规范

总则：**每个画面只允许一个主纹样主导**。模板把中心轴与视觉流线写死，页面只给尺寸、种子与位置比例（`cxRatio` / `cyRatio` / `radScale`）；辅助纹样一律更淡，且不得抢占主体的中心位置。

| 模板 | 用在哪 | 主纹样（唯一主导） | 辅助纹样 | 焦点 |
| --- | --- | --- | --- | --- |
| A 鸟群 + 圣徽 | 主视觉 / 重要标题（`SessionPage.qml`） | 圣徽复合环 + 贴边大鸟 + 两群鸟 | 光带、柔光、坐标网、黄金螺线、角度刻度、虚线弧、小圆徽、游标轴、印记、细规线 | 圣徽中心（`haloCore`） |
| B 羽翼 + 圣堂拱框 | 角色 / 核心内容（`FriendsPage.qml`） | 多重尖拱 + 玫瑰窗 + 对称双翼 + 龛位 | 光带、柔光、坐标网、柱列、拱洞穿行的远景鸟、底部层台、羽片带、小标签 | 龛位与龛上小圣徽 |
| C 鸟群 + 坐标轴 + 轨迹 | 技术展示 / 动态转场（`SettingPage.qml`） | 几何轨迹 + 沿轨迹的鸟群 + 放射圣徽 | 坐标网、多边形嵌套、角度刻度、分区标签、黄金螺线、五线谱符号、小标签 | 轨迹最高点那一簇鸟 |
| D 玫瑰窗 + 放射几何 | 沉浸背景 / 仪式画面（切页转场那一层） | 玫瑰窗 + 窗心圣徽 | 放射羽线、八边形嵌套、角度刻度、环形铭文、小标签、细规线 | 玫瑰窗中心 |
| E 深底羽兽墙 | 主视觉的另一种明暗调（`SessionPage.qml` 现在用这一套） | 冷灰底 + 一整片叠压的大鸟 + 左缘深蓝块 | 大圆弧、放射细线、点阵、角落等宽小注 | 前排最大的那只鸟 |

**模板 E**（`templateE`，缺省 `seed 71`）。照用户给的参考图做的**深底**一套（A–D 都是淡纸面，E 是冷灰底 + 浅色线）。参考图的读数是用 PIL 量的：2560×1106（2.31:1 宽幅）、背景冷灰（亮度均值 157，主色 #a0a0a0 / #90a0a0）、鸟是浅色细线（亮线均值 ≈ `#c3c8cc`）、左缘一块饱和深蓝 `#1040a0` 占 4.5%，背后有大圆弧、点阵与角落小字。实现取 `#a9b2b4 → #9aa5a8 → #8d999c` 的竖向渐变打底，左缘 8.5% 宽的 `#1040a0` 色块（带两条压深横带），点阵按整幅宽 24 列（不是 46 列 —— 1400 个 `arc+fill` 单这一项就吃掉一次重绘的一半时间），大圆弧 + 9 条放射细线压在鸟后面。鸟的**用量必须省**：这个模板单只鸟比 A 大一倍多、面积约 6 倍，实测 45 只 × `0.44h` 时每次重绘 55ms（18fps），所以最终是**四层 31 只**（前排 6 只 `0.40·min`、二排 7 只 `0.30·min`、三排 8 只 `0.20·min`、远景 8 只 `0.115·min`），前排两只开 `hatch`（翼面 4 道平行细纹，参考图里那种"羽面刻线"），实测每次重绘回到 `avg 15.8ms / 63fps`。留白：左缘蓝块右侧 0–0.10w 不放鸟（让色块立住），右上角留出放射线的空隙。

**模板 A**（`templateA`，缺省 `seed 21`）。主纹样圆心 `cx = w * 0.62`、`cy = h * 0.44`、`rad = min(w, h) * 0.27`；页面用 `cxRatio 0.635` 把主纹样推离左侧文字区。视觉流线是**三股**从画面左下穿到右上角的对角鸟潮（`x0 w*0.28, y0 h*0.99 → x1 w*1.08, y1 h*0.02`，`bow -h*0.09`，`streams 3`、`count 14`、`lateral min(w,h)*0.30`、`depthFall 0.46`、`wander 10`，`size min(w,h)*0.170`，α0.82，A–E 混排），贴着圣徽外环的是**两股**绕环飞行的鸟（`streams 2`、`count 9`、`rad * 1.62`、`lateral min(w,h)*0.16`、`0.125`、α0.68），右上角另压**三股远景鸟潮**（`streams 3`、`count 11`、`lateral min(w,h)*0.13`、`minGap 0.22`、`0.072`、α0.46、F 为主）。留白区：左侧 0–0.40w 全部留给刊头，上方 0–0.16h 保持空；大剪影压在右上（`w * 1.02, h * 0.06`）与左下（`w * 0.04, h * 1.02`）被边缘裁切。减弱规则：文字压上来时只允许把圣徽的 α 降一级（改 `line` 为 `iceDeep`），不得改圆心的比例；鸟群不因文字而消失，只允许整组延后显现。

**模板 B**（`templateB`，缺省 `seed 33`）。拱心 `cx = w * 0.5`、`baseY = h * 0.90`，拱宽 `aw = min(w * 0.62, h * 0.72)`、拱高 `ah = h * 0.80`；外拱 3 层环、内拱 2 层环，玫瑰窗嵌在拱头（10 瓣、半径 `aw * 0.17`、`cobalt` 线 + `iceDeep` 辅），双翼摆在拱肩线上（`wingY = baseY - ah * 0.52`，`span = min(w * 0.34, h * 0.44)`，各 16 片羽），中轴留给龛位（`aw * 0.22 × ah * 0.30`）与龛上小圣徽。留白区：两侧各 0.10w 的边距与画面顶部 0.12h。页面锁正方形宽高比，圆盘不会被拉成椭圆。减弱规则：窗口变窄时先减 `count`（双翼 16 → 12）、再减柱列，最后才让拱变淡；龛位与中心圣徽永不移位。

## 5 动态纹样规则

### 5.1 统一的时间入口

动画的唯一入口是 `opt.t`（0…1 的进度或相位，缺省 1）。几何函数本身不读时间，因此同一个模板既能做入场（`t` 从 0 长到 1），也能做静态图（`t = 1`）。

| 门槛 | 行为 |
| --- | --- |
| 全程 | 圣徽外环从 0 描圆到 `TAU * t`；`axisNet` 纵线按 `gx / w ≤ t` 逐条出现；`circularText` 按 `i / len > t` 逐字出现；`label` 按 `t` 逐字出现；`featherFan` / `wingBand` 按 `round(count * t)` 逐根出现 |
| `t < 0.34` | 玫瑰窗只画轮（stage 1） |
| `t < 0.72` | 加花瓣（stage 2） |
| `t > 0.6` | 模板 D 才允许出现环形铭文、标签与细规线（内部用 `(t - 0.6) / 0.4` 再归一化一次） |
| 常驻 | 只有 `phase` 在推进，改变的只有鸟 |

### 5.2 鸟的运动：滑翔、转向、远近

- **滑翔**：常驻时只有鸟群沿轨迹滑翔，几何完全静止。`phase` 每帧推进（见 5.7），`flock` 用 `flap = spec.flap * sin(phase * TAU + i * 0.7)` 给每只鸟一个相位差，再由 `bird` 转成三个可见变化：`lift = clamp(dihedral + flap * 0.16, 0, 0.62)` 让投影翼展按 `1 - lift * 0.34` 缩短、整体旋转再叠加 `-flap * 0.05`、`spanScale = 1 + flap * 0.10`。振翅表现为"展翼幅度 + 轻微俯仰"，不是上下扇动。
- **转向**：E 形态（`asym 0.26`）让两侧翼展不等；`flock` 在 `arc` 分支给航向加 `ang + π/2 + 0.18π`，在 `line` / `converge` 分支用 `atan2` 取切线方向，所以鸟头永远朝飞行方向。
- **远近**：四件事必须同时发生，缺一不可——尺寸（`size * lerp(sizeMin, 1, 1 - depth)`）、透明度（`alpha * lerp(0.36, 1, depth)`）、形态（`depth > 0.76` 换 F）、线色（`depth > 0.55` 用 `navy`，否则 `iceDeep`）。禁止只缩尺寸来表现远近。

### 5.3 羽片延迟跟随

羽片不是逐帧跟随，而是"逐根显现 + 相位错开"：`featherFan` 按 `t` 逐根长出（`shown = round(count * t)`，至少 1 根），`wing` / `wingBand` 的每片羽共享同一个 `t`，靠长度包络（由短到长）制造方向感；鸟群的相位错开由 `i * 0.7` rad 决定，相邻两只鸟相差约 40°、约 11% 的振翅周期。新加的羽片一律沿用这套延迟，不得引入独立的计时器。

### 5.4 圣徽：旋转与逐步描绘

- 逐步描绘：外环弧长随 `t` 生长（`0 → TAU * t`），内层的刻度（kind 3）、径向标记（kind 4）、射线（kind 6）透明度都乘 `t`，所以圣徽是"先出现一个圆，再长出细节"。
- 旋转：`halo` 没有时间项，常驻时不转。需要旋转的场景由模板 D 的显现顺序（轮 → 花瓣 → 窗格）与模板 A 的绕环鸟群来制造"环在动"的错觉；确实要转，也必须通过 `t` 与 `phase` 叠出来的角度参数，不允许在纹样里读系统时间。

### 5.5 玫瑰窗：分层显现与透光

分层由 `stage` 控制（1 轮 / 2 花瓣 / 3 外圈窗格），模板 D 由 `t` 自动切换（0.34 / 0.72 两个门槛），模板 B 固定 `stage: 3`。"透光"是两层叠加的结果：背后一层 `softGlow`（模板 B 在 `baseY - ah * 0.42` 放一团 `min(w,h) * 0.56` 的象牙白柔光）＋ 窗本身只用线不用面。因此玫瑰窗永远不做填充；需要更"透"时加大背后柔光的 `a`，而不是给窗加白色填充。

### 5.6 坐标线按序绘制

`axisNet` 纵线逐条出现、横线按 `t` 拉长、主坐标轴按 `t` 生长；`zones`、`angleScale`、`polygonNest`、`goldenSpiral` 的数量或透明度都乘 `t`。顺序固定为"网格 → 主坐标轴 → 刻度 → 分区标签"，与第 3.0 节的绘制顺序一致，保证文字与铭文最后出现。

### 5.7 12fps 重绘与性能预算

`MotifPlate.qml` 的重绘由内建 `Timer` 驱动：

- 间隔 `interval = Math.max(40, Math.round(1000 / Math.max(1, ambientFps)))`，缺省 `ambientFps = 12` → 83ms；即使把 `ambientFps` 调到 60，下限也是 40ms。
- 每帧只做两件事：`phase = (phase + 0.0016) % 1` 与 `canvas.requestPaint()`。相位一圈 625 帧，12fps 下约 52 秒，`flap = sin(phase * 2π) * 0.5` 每圈完成一次完整振翅周期。
- 预算：单页最多一块常驻动画图版；每帧只允许调一次 `MO.template()`；页面不得自己加 `Timer` 手动 `requestPaint()`（组件已内建）；`active`、`ambient`、`visible`、`revealed` 中任一为假时计时器停止，此时重绘次数必须为 0。

### 5.8 与外壳 `revealT` / `phase` 的对接

页面把外壳的入场状态直接透传即可，不要自己算进度：

- `revealT: revealed ? 1 : 0`，配 `Behavior on revealT { NumberAnimation { duration: T.DUR_ENTER + 420; easing.type: Easing.OutCubic } }`——切页时由外壳把 `revealed` 置为 false 再置 true，纹样因此从 0 缓动到 1（总时长约 840ms）。
- `onPaint` 里把 `t` 传成 `Math.max(0.001, revealT)`，保证第一帧也画得出东西；`phase`、`flap`、`sealText`、`mark`、`caption` 一并传下去，`cxRatio` / `cyRatio` 只在 `>= 0` 时传、`radScale` 只在 `> 0` 时传，否则让模板用自己的缺省值。
- 动效档位为"最低"时，外壳把 `ambient` 置为 false（常驻动效关闭，`revealed` 直接置 true），纹样必须仍是一张完整的静态图。
- 页面侧的写法固定为四行：`active: page.active !== false`、`revealed: page.revealed !== false`、`ambient: page.ambient !== false`，配合 `template` / `seed`。

### 6.2 `MotifPlate.qml` 属性

`template`（缺省 `"A"`）、`seed`（21）、`active`（true）、`revealed`（true）、`ambient`（true）、`cxRatio`（-1，表示用模板缺省）、`cyRatio`（-1）、`radScale`（-1）、`sealText`（""）、`mark`（"S"）、`caption`（""）、`ambientFps`（12）；另有只读进度 `revealT` 与 `phase`。内部是一个 `Canvas`（`renderStrategy: Canvas.Cooperative`、`antialiasing: true`），`onPaint` 里先 `ctx.reset()` 再 `clearRect`，不画自己之外的任何底色。重绘触发点只有六处：宽变、高变、`revealT` 变、`template` 变、`active` 变（为真时）、`Component.onCompleted`（为真时）——所以页面改任何纹样参数，都必须落在这些属性上，否则不会刷新。

### 6.3 在页面里新增一处纹样的步骤

1. 在 `motifs.js` 里用现成的基础件拼出几何，新增函数必须带 `t` 参数、只用 `lw()` 与 `alpha()`、颜色取 `C` 里的令牌；属于主纹样的写进对应模板，属于局部装饰的先在 `flock` 之外单独成一个组合件。
2. 若是新的整页构图，新增 `templateE` 之类的模板函数，并在 `template()` 里加分支；**不允许**页面绕过 `template()` 直接调原子函数。
3. 在页面里放 `MotifPlate`，只写 `template` / `seed` / `cxRatio` / `cyRatio` / `radScale` / `sealText` / `mark` / `caption` 与四个状态透传；位置用 `anchors`，`seed` 每页取不同的值（现有 A 61、B 97、C 131），避免两页长一样。
4. 在 `source/app_qml/qml.qrc` 里登记新增文件：`qml/plate/*.js` 与 `qml/Components/*.qml` 各占一行 `<file>…</file>`，与相邻条目保持同样缩进。
5. **改完必须重跑 qmake 再编译**（`source/app_qml/app_qml.pro`）。qrc 里的资源由 rcc 在构建时生成，不重跑 qmake 就不会重新编译资源，表现为"改了没效果"——遇到这种情况先怀疑 qmake，不要去改代码。

### 6.4 复用约定

- 一处纹样只能有一个来源：几何在 `motifs.js`，装配在 `MotifPlate.qml`，页面里出现的所有 `Canvas` 都不应再画纹样。
- 页面里禁止出现 `1.2`、`0.7` 这类裸线宽与裸透明度，全部交给 `lw()` / `alpha()`。
- 新增颜色必须先进 `C`，再在子系统里引用；不得在模板里写十六进制。
