  字重 300 (light)：保留 39/188 个子集
  字重 400 (regular)：保留 39/188 个子集
  字重 600 (demibold)：保留 39/188 个子集

复现步骤：
  npm i --no-save misans-webfont@4.3.1
  node tools/prepare-misans.cjs
  npm uninstall --no-save misans-webfont
