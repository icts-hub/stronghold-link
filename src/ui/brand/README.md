# 品牌符号插槽

界面上所有 ∞ 符号都来自同一个来源变量（`src/ui/styles/rhine-dynamic.css` 里的 `--shl-mark`）：

- 默认值是**本项目的自绘符号**（连续笔画双环 ∞ + 交叉处方形节点），随主题自动变色。
- 如果你想换成**自己的素材**，把文件放到本目录（例如 `mark.svg`），然后改一行：

```css
:root {
  /* 用你自己的文件替换内置图形；放进来即生效，不需要改任何脚本 */
  --shl-mark: url("brand/mark.svg");
}
```

会立刻生效的地方：顶栏品牌位、每个页头的大号水印、侧栏底部、启动序列中央。

## 请注意（这不是技术限制，是法律事实）

如果你放入的是**第三方作品的官方标识**（例如《明日方舟》莱茵生命的 logo）：

1. 它是鹰角网络的商标与版权资产，商标保护与"是否二创"是两件事；
2. 本项目以 **GPL-3.0 公开发布**，属于"向公众分发"，不是个人自用；
3. 多数厂商的二创规约明确**不允许使用官方 logo / 商标**，即使非商业；
4. 因此这个替换动作**由你自己决定、由你自己执行**，风险与后果由你承担。

本项目自带的 `--shl-mark` 默认图形是原创的，可安全随软件分发。
